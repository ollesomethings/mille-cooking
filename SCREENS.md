# Prototype screens

## Scenario launcher

A once-per-session "This is a demo." disclaimer dialog (`src/components/proto/disclaimer.tsx`, mounted at the root in app/_layout.tsx) overlays whatever screen the session opens on — launcher or preset links — stating nothing is live in the real app, all data is mock, and everything shown is in the works.

Playlists ("share your taste", MMT spec): a first-class hub entity type alongside notes/moments/swaps — never a tool-set card. The mentor's "this is my vibe" playlist (`src/data/playlists.ts MENTOR_FIRST_PLAYLIST`, 7 songs) is auto-delivered on match: seeded with the fixtures for existing teens, added beside the welcome note in `completeOnboarding` for new teens (so it tops a new teen's hub), each with a tappable "Noah made you a Playlist" chat event line (kind `playlist-event`, links to the artifact). Viewer `/hub/playlist/[id]`: cover (moodie on tint + vinyl grooves), song rows with spinning mini-vinyl snippet playback (15s, simulated — `[audio stub]` console log, "TAP A SONG FOR A SNIPPET"), per-song heart reactions (teen can un-react; mentor's reaction shows their mini avatar on the heart) and a per-song chat jump that prefills the input ("wait you like {song}?? " via app-store.chatDraft + nav-store.requestChat). Builder `/hub/create-playlist` from the hub FAB ("Make a playlist"): title + Caveat title-idea chips, 4 default moodie covers, search over a 20-song mock catalog, 1–10 cap shown as "n/10", CTA "Send to {mentor}" (no private playlists — sharing IS the save: hub entity + chat event line + confetti sent screen). Simulated mentor presence follows the chat's existing rules: ONLINE, the mentor reacts to one song of a sent playlist (+"JUST listened…" message) and follows up once per playlist when the teen reacts (store-guarded `mentorNoticed`); OFFLINE, nothing arrives and the sent screen says "they'll hear it at 5pm ET". The offline chat block gets a second chip ("Noah made you a playlist", offline_playlist_chip_tapped) so a new teen's empty-chat first moment has someone to get to know. Analytics: playlist_opened/snippet_played/song_reacted/chat_jump/sent. Dev hooks `window.__app`/`window.__hub` added for headless verification. Real-app scope, documented not built: mentor dashboard (library, 1-many resend, sent indicators), moderation/admin visibility, rematch consent (rematch auto-delivery itself comes free from the seeding logic), teen cover uploads/stickers/edit/delete (P1/P2).

A once-per-session Hub coach mark (`src/components/proto/hub-coachmark.tsx`, mounted in the home pager) nudges chat toward the Hub, Jomo/Bumble-style: 1.4s after landing in chat (post-disclaimer) the screen dims, the "Your space" header pill stays lit under a pulsing halo (position measured via `measureLayout`, with a layout-derived fallback), a hand-drawn SVG arrow points at it, and a black bubble (Caveat eyebrow "psst — up there", Avantt headline "Chat isn't all there is.") offers Got it / an arrow CTA. Pill or arrow → Hub via requestHub (hub_opened{source: coachmark}); backdrop or Got it dismisses; visiting the Hub first suppresses it. Skipped on `/calm` links and mentor-offline sessions — those have their own pointer cards, one nudge per session max. Analytics: hub_coachmark_shown/dismissed.

Shareable preset link: `/calm` (app/calm.tsx) skips the launcher entirely — seeds the existing-teen scenario with the calming tool set on and lands in CHAT with a dismissible pointer card ("Psst — your space has calming tools now", `src/components/hub-hint-card.tsx`) that scrolls the pager to the Hub (hub_opened{source: chat_hint}). Send this URL to testers who should see the mental-health tools without touching any toggles; reloading mid-session returns to the launcher, reopening the link re-seeds.

The app opens on a prototype-only launcher (`src/components/proto/scenario-picker.tsx`, gated in `app/index.tsx`) — responsive: the content column scrolls, the phone fan renders behind it and only on viewports ≥680px tall, and fan size scales with both axes, so the option toggles are visible or reachable at every screen size. The "Know your mentor" toggle row is currently hidden (feature stays wired via scenario-store.mentorTools; re-add the ToggleRow to restore). Two scenario cards with descriptions (**New teen** 🌱 / **Existing teen** 💬) plus a session-options group with brand toggle switches (`src/components/proto/toggle-switch.tsx`): "🌙 Mentor offline" and "⏭️ Skip onboarding" (new-teen only — `chooseScenario` + immediate `completeOnboarding('John')`, landing in chat already matched, no signup questions). **New teen** runs the FULL onboarding (`app/onboarding.tsx`, structure/copy/components from `mono/link-v2 (auth)+(onboarding)`): welcome → phone → OTP → state → preferred-name → legal name → birthday → zipcode → sex → pronouns → race/ethnicity → expectation-setting pager (4 slides, blueLoops bg) → ideal-vibe → mentors-loading (Moodie) → we-found-match (collage) → mentor detail (hero + vinyl + voice note, "say hi to {name}") → mentor browse ("Your matches" carousel + "Choose for me") — and lands in a fresh account; the chosen mentor (`src/data/mentor-candidates.ts`, real photos from mono assets) drives avatars/greeting/welcome note app-wide. Intro video and the post-match "get to know {mentor}" story flow are NOT built yet. **Existing user** seeds three weeks of history with Noah. Scenario state: `src/stores/scenario-store.ts`; reload to switch.

Status: **stub** (renders, minimal interaction) · **interactive** (full flow works) · **polished** (reviewed on a real phone).

## Offline-hours self-care flow

## Hub = the teen's space (tools + with-mentor)

There is exactly ONE surface where tools live: the Hub pane of the home pager (`src/components/hub-tab.tsx`) — no separate sheet or route. Restyled again (Oct 12) to the "U cooking" mock — the Hub pane is now TWO views behind a floating beige Home | Journey pill (always above the pinned crisis link, over a legibility fade): HOME = icy gradient sky (#EAF1FC→#F7FAFF, header strip matches), big left-aligned editable hub name (HubName hero variant) + S-M-T-W-T-F-S week strip (today in dark pill), centered interactive "today I will / {intention}" with a green highlighter swipe (tap to cycle 7 intentions, src INTENTIONS), a snap carousel of the latest artifacts (white 154px cards: vinyl outline for playlists / photo thumb / glyph + title + sand bar + dots; the recommendation slot folds in as the first card "FOR RIGHT NOW" with sparkles), a compact 2-col grid of EVERY tool + activity (clean white cards with Avantt bold label + secondary metadata subs: '2 min · Reset', 'Prompt · Free', 'Co-op vinyl', etc. — no to-do checklist or 'done' badges; always ready when needed), and a tactile "With {mentor}" Keepsake Folder peek card (physical folder tab 'YOUR KEEPSAKES', stacked polaroid thumbs with realistic drop-shadows and rotations, "{n} shared memories and counting") switching to JOURNEY = category filter pills (All, Moments, Notes, Playlists, Swaps) over the full rotated scrapbook grid + ForYouCards + swap banner. hub_view_changed{view} analytics. Earlier description of the single-scroll layout: cream canvas (#F8F5EF, header strip matches per-pane), Tools as clean white 2-col cards with soft shadows (hand-drawn ToolGlyph + label + sand LabelBar, no tinted bgs/scribbles/subs), "With {mentor}" as full-width white activity ROWS so every paired activity is one flow — live rows (Playlists → /hub/create-playlist, 20 questions, Vibe boards, Make a story — the know-tools are now always reachable, no toggle needed; hub_activity_opened{activity}) with chevrons, coming ones greyed with a SOON tag (Connection cards, Hot takes, Deep thoughts) — and the artifact grid now titled "Your journey". Structure top-to-bottom: header (relationship name "da boyzz", "Since October 2025" — unchanged), Recommended slot (hidden unless `src/lib/recommendation.ts` `getRecommendation()` returns one; set-aware prototype rule: midnight–6am local recommends Calm my body ("It's late. Launcher toggle "Know your mentor" (`scenario-store.mentorTools`, mutually exclusive with the mental-health toggle) swaps the Hub's tools for the icebreaker set (`MENTOR_TOOLS`), built from the "Get to know your mentor" whiteboard: `/know/questions` (20 questions — 8 flip cards (rotateY, tap the question and it turns over) with deck pips; the mentor's answers are pre-left with his intro and labeled "ANSWERED WITH NOAH'S INTRO · NOT LIVE"; optional typed answers, sent to chat at the end as ONE message or kept private), `/know/songs` (Our playlist — the mentor started one with his intro: three tracks + his on-repeat spinning on a hand-built vinyl with a droppable tonearm, hold the record to stop it; the teen digs through an 8-track crate, adds three (dashed slots fill with YOU rows), names it (Caveat input + suggestion chips) → hub note with the full tracklist + a chat message), `/know/boards` (Vibe boards — the mentor's 4-image board from his gallery assets; teen pins 3 from a 9-image pool into dashed board slots (spring in, tap a slot to unpin) → hub moment "vibe board, for Noah"), `/know/story` (Make a story — photo + eyebrow chip + headline with live preview → real story entity on the hub, opens in the existing story viewer). Shared exit: `know-finish.tsx` (confetti + Back to your space). Analytics: know_tool_completed{tool,…}, know_answers_sent. No simulated presence anywhere — everything from the mentor is framed as pre-left intro content.

Launcher toggle "Mental health tools" (`scenario-store.mentalHealthTools`) swaps the Hub's tool set for the calming line-up (`CALM_TOOLS` in `src/data/selfcare-tools.ts`): Calm my body (same breathing tool), Back to your senses (the grounding hunt, sub '5 you see, 4 you touch… ~2 min'), `/selfcare/paint` (Paint it calm — pick a subject first: Evening lake / Night sky / Window plant, each ~9 hand-drawn SVG regions with numbered paints; wrong taps are a soft no-op, per-fill burst; finishing springs in a polaroid keepsake ('night sky — sep 21') with 'Keep it in your space' — adds the finished painting to the hub grid as a real moment entity (SVG data-URI image, caption 'painted: …', paint_kept analytics) — or 'Let it go'), `/selfcare/star` (Star breathing, after Dr. Juliet Young's exercise, credited on screen — finger-trace the ten edges of a five-point star, each edge a breath phase (In/Hold/Out) that fills with its color under your finger; finger position projects onto the current edge, forward-only, with a 48px wander tolerance and no punishment; corner haptic ticks, lap success buzz, 2 laps to finish; "Guide me" auto-traces as the tap alternative), and `/selfcare/calmdeck` (Calm cards — shuffled deck of 14 one-line calm-down tips, swipe or tap the top card away, spring-back on short drags, hairline progress; finishing the deck plays a finale: the five card backs spring into a fan with confetti, 'That's the whole deck.' / 'fourteen ways down, whenever you need one.'). Both new tools keep the crisis link and "Stop early"/"I'm done" exits, and report offline_tool_completed (regions_filled / tips_seen).

Launcher toggle "Mentor offline" (`scenario-store.mentorOffline`) works with both scenarios and combines with Skip onboarding (offline + skip = fresh account, holding message, no greeting). Offline chat (`src/components/mentor-offline-block.tsx`): live countdown to 5pm ET ("Noah is back in 9h 24m", `offline.ts mentorReturnCountdown`, offline_countdown_seen), dimmed resting message history, AUTO-MESSAGE holding bubble, and a dismissible pointer card into /space (a heads-up, never a modal/auto-launch). Tool exit (`/selfcare/done`) primary CTA is context-aware: offline → "Remind me when {mentor} is on", online → "Go to your chat"; secondary "Back to your space". Chat then shows `src/components/mentor-offline-block.tsx`: honest availability ("Noah is back at 5pm ET"), the mentor's holding message labeled AUTO-MESSAGE (never a simulated live person — a new-user signup gets NO greeting), the opt-in card ("Having a hard moment right now?" → never auto-launched), and the crisis link. Flow routes: `/selfcare` (picker, 2×2 grid: Calm my body / Get it out / Back to your senses / Show me I'm not alone) → `/selfcare/breathe` (box breathing 4-4-4-4 as a graffiti piece: phase-colored circle/background via interpolateColor, spray-splat bursts per phase, twin counter-rotating halos, in-circle 4-3-2-1 count with tick haptics, box-progress dots; 2-min default, stop anytime), `/selfcare/vent` (private by default, optional share-with-mentor; desk toolbar: 5 fonts, 5 inks, 4 papers, draggable zine stickers — tinted brand scribbles + handwritten Caveat/Avantt word stickers ('ugh.', 'SO DONE', 'fr fr'…), drop-to-toss trash zone — PanResponder, paper measured by a plain View since LinearGradient/Animated.View don't forward onLayout on web), `/selfcare/ground` (Back to your senses — 5-4-3-2-1 grounding, tap-based by default: the camera is OPT-IN via an in-app chip on the "see" step only (no uninvited browser permission prompt mid-crisis), local-only and says so, gracefully degrading when denied; with camera on, "I see one" grabs the frame in-memory ~1s: polaroid pops then explodes into confetti; per-sense CTAs (I can feel it / I hear one / …), a no-fail "Can't find one? Skip it — still counts." on every step (ground_sense_skipped), X to leave early (ground_exit_early). Ends in a one-tap Moodie check-in ("How's your head now?" — A little better / About the same, ground_checkin) that branches: better → "That's a skill, not luck." hope-loop to the mentor + opt-in one-shot "Let {mentor} know I did this" (off by default, drops a labeled event line in chat, never a simulated reply — ground_shared_with_mentor); same → "That's okay" + Go again (ground_restart) + "Try breathing instead" + crisis card promoted from footer link to a visible card. The offline chat block also gets a one-tap chip straight into it: "2 minutes, out of your head" (offline_ground_chip_tapped) — no Hub digging for dysregulated new teens), `/selfcare/notalone` (read-only anonymous confessions feed: once-per-session intro, theme chips, one full-screen card at a time, breather card every 9, hairline progress, anonymous per-card "me too" resonance (no counters, no names, nothing sent — confession_me_too analytics only) with a WordBurst of rising handwritten agreements ('same', 'fr', 'this') + spray dots in the theme color; per-theme paint colors on label/progress; still no comments/sharing/submissions — data in `src/data/confessions.json`, 58 real anonymized safety-passed submissions, clinical review still required before shipping) → `/selfcare/done` (tie-back + "Remind me when they're on" push stub; not_alone variant adds "Talking to someone who gets it is the next step."). `/resources` mirrors mono's mentor-offline sheet (911/988/Crisis Text Line/Warm Line, tel:/sms: links) and is one tap from chat (shield icon too) and from every self-care screen via `TalkNowLink`. Tool identities are hand-drawn SVG glyphs (`src/components/proto/tool-glyphs.tsx` — wobbly marker strokes, no emoji anywhere in tool chrome); the not-alone intro art is the 'tired' Moodie. Analytics per spec in `src/lib/analytics.ts` (console, hour bucket + 0–6am flag). Haptics via `src/lib/buzz.ts` — real on native, navigator.vibrate on Android web, console elsewhere (`src/web/expo-haptics-stub.ts`). Out of scope: mentor-side visibility, voice vent, streaks; confessions submissions/moderation/reactions (ADT-6).
